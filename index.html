Socks5 节点转 Clash 配置文件

支持输入 ip:port:user:pass 或 socks:// 链接，一键生成并下载符合标准格式的 Clash YAML 配置文件！

📖 YAML 配置文件使用方法：

1. 点击上方 “下载 YAML 文件”（保存为 config.yaml）或点击 “复制 YAML” 手动粘贴。

2. 打开你的 Clash 客户端（如 Clash Verge Rev、Clash for Windows 等）。

3. 切换到 “配置文件 (Profiles)” 页面，将下载好的文件拖入客户端，或通过本地导入功能选中该文件。

4. 激活该配置文件即可开始使用！
